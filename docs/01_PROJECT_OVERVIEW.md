Aqui vamos explicar o que estamos construindo.

Uma hipótese inicial seria:

Modernização progressiva do sistema de gestão imobiliária atualmente utilizado pela cliente, substituindo uma aplicação legada por uma solução moderna, modular, segura e preparada para evolução, mantendo como requisito crítico a continuidade das operações financeiras e, especialmente, a emissão e controle de boletos.

Mas isso ainda será marcado como hipótese de projeto, não como requisito fechado.
